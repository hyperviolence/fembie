# Model evidence

- [Generic transdermal gel](TransdermalGel.md): original dose-only approximation
  using EstroGel and Divigel prescribing information; not clinically validated.
- [Valerate intramuscular](ValerateIntramuscular.md): Estrannaise port.
- [Enanthate intramuscular](EnanthateIntramuscular.md): Estrannaise port.
- [Enanthate subcutaneous](EnanthateSubcutaneous.md): adaptation and limitations.

Before implementing the enanthate/subcutaneous model, record primary sources,
route, formulation/vehicle, population, sampling times, assay, dose basis,
equations, units, parameter fitting, extrapolations and validation limits.

Research starting point: https://pubmed.ncbi.nlm.nih.gov/3814225/
This citation is not proof of a validated subcutaneous model. Review the full
paper and additional primary evidence before selecting any parameters.

Version model specifications and retain provenance with predictions.
